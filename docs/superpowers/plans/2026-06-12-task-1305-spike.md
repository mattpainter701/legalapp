## Task 3: Evaluate Against Go/No-Go Criteria

Once LawToolBox responds (or by EOD if no response), evaluate:

- [ ] **Step 1: Create decision matrix**
  ```markdown
  ## Evaluation Matrix

  | Criterion | Ideal | Minimum | LawToolBox Response |
  |-----------|-------|---------|---------------------|
  | Pricing | <$1K/month | <$5K/month | [answer] |
  | API available | REST + SDK | REST only | [answer] |
  | Coverage | 50 states | 40+ states | [answer] |
  | TTM | 2-4 weeks | 4-8 weeks | [answer] |
  | SLA | 99.9% uptime | No requirement | [answer] |
  | Competitor usage | Clio verified | Any major firm software | [answer] |
  ```

- [ ] **Step 2: Score each criterion**
  - GREEN (meets ideal)
  - YELLOW (meets minimum, not ideal)
  - RED (below minimum or blocker)
  - Example scoring:
    - Pricing $2K/month = YELLOW (affordable but pricey)
    - Pricing $50K/month = RED (budget blocker)
    - REST API + docs = GREEN
    - No API = RED

- [ ] **Step 3: Determine go/no-go status**
  - **GO:** All GREEN, or mostly GREEN + 1-2 YELLOW on non-blockers
  - **MAYBE:** Multiple YELLOW, no RED (conditional go — needs clarification)
  - **NO-GO:** Any RED in pricing/API availability/coverage/TTM
