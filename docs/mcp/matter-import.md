# Matter import artifact boundary

Folder/ZIP imports are staff REST operations, not Workspace MCP tools. Imported
documents and EML correspondence become normal matter-scoped artifacts and keep
the destination's access and portal-visibility rules. An agent must not infer
that historical email authorizes a new task, message or legal deadline.

See [the canonical import guide](../matter-folder-import.md) for confirmed
mappings, provider storage routing, provenance, retry semantics and limits.
